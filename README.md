# COVID-19 Interactive Dashboard

An interactive COVID-19 dashboard built using **Python**, **Pandas**, **Plotly**, and **Dash**, and run in **Google Colab**.

## 🔍 Features
- Day-wise global trend line chart
- Country-wise interactive bar charts
- Top 10 countries by total cases
- Pie chart of global death distribution

## 📁 Files
- `day_wise.csv` – Daily global cases
- `country_wise_latest.csv` – Latest country-level stats
- `worldometer_data.csv` – Country-level data (for bar and pie charts)
- `dashboard.ipynb` – Google Colab notebook with full dashboard

## 🚀 Tools Used
- Google Colab
- Pandas
- Plotly
- Dash
- Pyngrok
